# Biblioteca de Studio

Funciones reales:
- Reúne imágenes y Reels exportados desde Studio.
- Buscar contenido por texto.
- Filtrar por tipo cuando las opciones están visibles.
- Ver miniatura, nombre, tipo y fecha.
- Descargar contenido.
- Abrir o reutilizar contenido compatible.
- Eliminar contenido con confirmación.
- Actualizar la lista manualmente.

No existe sincronización automática con Canva, CapCut, Google Drive ni bancos externos.
